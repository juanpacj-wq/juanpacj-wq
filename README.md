#### What I've shipped in the last year

- **A bilingual corporate website** (134 pages, WordPress with a custom block
  theme and plugins): reproducible Linux deployments with automatic rollback,
  WCAG 2.2 AA, and an external penetration test that closed with only 3
  low-severity findings.
- **A digital operations logbook for two thermal power plants** that replaced
  Excel-based logging: React, Node.js, WebSockets, SQL Server and Entra ID SSO,
  covered by more than 600 automated tests.
- **Real-time telemetry for power plants**: energy meters read over Modbus TCP
  every 2 seconds (15 to 25 ms latency), published to Microsoft Fabric and
  Power BI.
- **A rescued legacy e-invoicing pipeline** (Airflow, Selenium, Oracle,
  MongoDB): from zero to 151 tests with CI and a protected main branch,
  without stopping daily operations.
- **An event platform** for a corporate forum with 160+ guests: QR
  credentials, Microsoft Graph and 156 certificates generated and verified in
  code.
